# vk-ui

Веб-мессенджер аккаунта ВКонтакте в облике vk.com: диалоги, переписка, отправка текста, фото и голосовых. Только UI
поверх API VK. Панель ничего не хранит: ни на диске, ни в базе.

## Требования

- Docker + Docker Compose для деплоя или Python 3.12 для локального запуска; локально для голосовых нужен `ffmpeg`
  с `libopus` — мессенджер перекодирует `.mp3` в голосовое (в образе он есть).
- User-токен VK из-под официального приложения: обычные токены не имеют доступа к `messages.*`.

## Деплой

```bash
cp .env.example .env   # VK_TOKEN, WEB_PASSWORD, WEB_DOMAIN
docker compose up -d --build
```

Панель открывается на `https://<WEB_DOMAIN>:8080` — нужен открытый порт 8080. Перед ней стоит `caddy`: сертификат
самоподписанный (`tls internal`), браузер один раз попросит подтвердить исключение; по `http://` на этот порт
не зайти. Пароль `WEB_PASSWORD` вводится один раз в форме входа: браузер остаётся в панели до кнопки «Выйти» или
смены пароля. После 5 неверных паролей IP блокируется на 15 минут. Панелью удобно пользоваться с телефона.

Обновление: `git pull && docker compose up -d --build`.

## Мессенджер

`/im` — раскладка как в VK: слева диалоги (поиск по названию, фильтр непрочитанных, `Ctrl/⌘+K`), справа чат.
Новое приходит сразу: с первого открытия мессенджера панель держит свой long poll VK и шлёт браузеру событие,
а тот дотягивает сообщения; старые подгружаются при прокрутке вверх.

- Отправка текста, ответ с цитатой, удаление своих сообщений.
- Фото — до нескольких штук за раз; голосовые — `.ogg` (Opus) или `.mp3`, mp3 перекодируется в Opus через `ffmpeg`.
  Файлы на диск не сохраняются.
- Поиск по всем чатам; вложения чата по типам: фото, видео, файлы, ссылки, голосовые.
- Отметка «прочитано» ставится только кнопкой: открытие чата прочитанным его не делает.
- Архивные чаты и служебные сообщения «ВКонтакте» (входы в аккаунт и т.п.) не показываются никогда: ни в списке,
  ни в поиске, ни по прямой ссылке.

Не умеет: стикеры, эмодзи-пикер, отправку файлов.

## Настройки

`.env` (читается при старте):

| Переменная | Дефолт | Что делает |
|---|---|---|
| `VK_TOKEN` | — | user-токен VK |
| `WEB_PASSWORD` | — | пароль панели; без него она не стартует |
| `WEB_DOMAIN` | — | IP или домен панели для Caddy (HTTPS на порту 8080) |
| `WEB_HOST` | 127.0.0.1 | адрес, на котором слушает панель; образ сам задаёт `0.0.0.0`, чтобы до неё дошёл Caddy |
| `WEB_TIMEZONE` | Europe/Moscow | часовой пояс для дат в мессенджере |

## Приватность

- Тексты сообщений не пишутся в логи. Из VK на диск не сохраняется ничего: ни переписка, ни файлы.
- VK-токен вырезается из всего, что панель отдаёт наружу, включая тексты ошибок.
- Панель видна только через Caddy по HTTPS; порт самой панели наружу не публикуется.

## Локальная разработка

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest
WEB_PASSWORD=pw .venv/bin/python -m web.app   # панель на 127.0.0.1:8080
```

Токен VK берётся из `.env`.
