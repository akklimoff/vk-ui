# vk-ui

Веб-панель агента ВКонтакте [vk-mcp](https://github.com/akklimoff/vk_mcp): статус бота, персоны, промпт, настройки,
доверие, журнал действий агента, песочница и мессенджер `/im` в облике vk.com.

Отдельный сервис со своим образом. С ботом панель делит только данные: его `config/` (панель их правит), `state/`
(только читает) и docker-сеть, в которой виден сервис `ai`. Код ни от чего снаружи не зависит: нужное панели ядро
агента (`bot/`, `ai/`, `common/`) лежит здесь — снимок vk-mcp от 2026-10-18 (4e0382a), дальше живёт своей жизнью.

## Требования

- Docker + Docker Compose для деплоя или Python 3.12 для локального запуска; локально для голосовых нужен `ffmpeg`
  с `libopus` — мессенджер перекодирует `.mp3` в голосовое (в образе он есть).
- Работающий бот vk-mcp рядом: его `config/`, volume со `state/` и сервис `ai` в общей сети.
- Тот же user-токен VK, что у бота: из-под официального приложения, обычные токены не имеют доступа к `messages.*`.

## Деплой

```bash
cp .env.example .env   # VK_TOKEN, WEB_PASSWORD, WEB_DOMAIN и где лежат данные бота
docker compose up -d --build
```

Где искать данные бота, задаётся в `.env`: `BOT_CONFIG_DIR` — путь к его `config/`, `BOT_STATE_VOLUME` — имя volume
со `state/`, `BOT_NETWORK` — сеть, в которой виден `ai`. Контейнер работает от uid 1000 и пишет в `config/` бота:
папка должна принадлежать этому uid (`chown -R 1000:1000`).

Наружу панель выходит через `caddy` по HTTPS: `https://<WEB_DOMAIN>`, нужен открытый порт 443. Сертификат
самоподписанный (`tls internal`) — браузер один раз попросит подтвердить исключение. Пароль `WEB_PASSWORD` вводится
один раз в форме входа: браузер остаётся в панели до кнопки «Выйти» или смены пароля. После 5 неверных паролей IP
блокируется на 15 минут. Панелью удобно пользоваться с телефона.

ИИ панель берёт у сервиса `ai` бота (`AI_URL=http://ai:8090`). Без `AI_URL` LLM работает внутри панели, и ключи
провайдеров нужны в её `.env`. Потолки агента и лимиты частоты панель показывает из своего `.env` и применяет
в песочнице: держи их равными `.env` бота.

Обновление: `git pull && docker compose up -d --build`.

## Страницы

- **Мессенджер** — диалоги и переписка аккаунта; у каждого чата видно, слушает ли его агент, а в панели чата —
  доверие беседе, заметка, пауза, персоны, доверенные участники.
- **Статус** — жив ли бот, какая модель отвечала последней, ошибки, пауза; действия, которые ждут «да»; почему агент
  промолчал: кто и где тегал, но не был услышан (фильтр, лимит частоты, полная очередь) — без текста сообщений.
  От отказа «беседа не в доверенных» ссылка ведёт на «Доверие»; сам статус доверие не выдаёт.
- **Персоны** — файлы персон и выбор активной.
- **Промпт** — собранное системное сообщение агента по слоям, для любой беседы.
- **Доверие** — доверенные люди, доверенные беседы и заметки о них. Ник при добавлении сохраняется как id: ник можно
  перерегистрировать на другого человека. Доверие беседе — право каждого доверенного человека командовать всем
  аккаунтом из неё: перед «Доверять» сверь название и номер беседы.
- **Настройки** — модель, температура, пауза; потолки агента показаны для справки, меняются они в `.env`.
- **Журнал** — что агент делал: просьба, вызовы с параметрами и вердиктами, исход. Результаты вызовов не показываются
  и не хранятся: в них чужая переписка. Ответ агента можно удалить в VK.
- **Песочница** — пробный прогон: агент получает просьбу и работает как настоящий, но в VK ничего не пишет, ответ
  не отправляет и следа в журнале не оставляет.

Прав агента в панели нет: они заданы кодом бота и правятся только там.

### Мессенджер

`/im` — раскладка как в VK: слева диалоги (поиск по названию, фильтр непрочитанных, `Ctrl/⌘+K`), справа чат.
Новое приходит сразу: бот отмечает в `state/` каждую пачку событий long poll, панель шлёт браузеру событие, и тот
дотягивает сообщения; старые подгружаются при прокрутке вверх.

- Отправка текста, ответ с цитатой, удаление своих сообщений, участники беседы.
- Фото — до нескольких штук за раз; голосовые — `.ogg` (Opus) или `.mp3`, mp3 перекодируется в Opus через `ffmpeg`.
  Файлы на диск не сохраняются.
- Поиск по сообщениям во всех чатах; вложения чата по типам: фото, видео, файлы, ссылки, голосовые.
- Отметка «прочитано» ставится только кнопкой: открытие чата прочитанным его не делает.

Не умеет: стикеры, эмодзи-пикер, отправку файлов.

## Настройки

`.env` (читается при старте):

| Переменная | Дефолт | Что делает |
|---|---|---|
| `VK_TOKEN` | — | user-токен VK, тот же, что у бота |
| `WEB_PASSWORD` | — | пароль панели; без него она не стартует |
| `WEB_DOMAIN` | — | IP или домен панели для Caddy (HTTPS) |
| `WEB_HOST` | 127.0.0.1 | адрес, на котором слушает панель; образ сам задаёт `0.0.0.0`, чтобы до неё дошёл Caddy |
| `WEB_TIMEZONE` | Europe/Moscow | часовой пояс для дат в мессенджере и для «сейчас» в песочнице |
| `AI_URL` | — | адрес ИИ-сервиса бота; пусто — LLM работает внутри панели |
| `AI_TIMEOUT_SECONDS` | 200 | сколько панель ждёт ответа `ai` |
| `LLM_TEMPERATURE` | 0.8 | температура по умолчанию (переопределяется в настройках) |
| `AGENT_MAX_STEPS` | 16 | шагов модели на просьбу в песочнице |
| `AGENT_TIME_BUDGET_SECONDS` | 240 | секунд на просьбу в песочнице |
| `AGENT_RESULT_CHAR_LIMIT` | 12000 | сколько символов одного ответа VK видит модель |
| `AGENT_CONFIRM_TTL_SECONDS` | 300 | сколько секунд бот ждёт «да» (для справки на странице настроек) |
| `USER_COOLDOWN_SECONDS` | 2 | пауза между просьбами одного человека (для справки) |
| `CHAT_LIMIT_PER_HOUR` | 60 | максимум просьб на беседу в час (для справки) |
| `GLOBAL_LIMIT_PER_MINUTE` | 30 | общий максимум просьб в минуту (для справки) |
| `ACCESS_FILE` | config/access.json | списки доверия бота |
| `RUNTIME_FILE` | config/runtime.json | живые настройки бота: персона, модель, пауза, температура |
| `PERSONAS_DIR` | config/personas | файлы персон |
| `STATE_DIR` | state | статус, журнал, ожидающие «да», отказы и отметки long poll бота |
| `BOT_CONFIG_DIR` | — | для compose: путь к `config/` бота |
| `BOT_STATE_VOLUME` | vk_mcp_state | для compose: volume со `state/` бота |
| `BOT_NETWORK` | vk_mcp_default | для compose: сеть, в которой виден `ai` |

Пути в контейнере — `/app/config` и `/app/state`, их подставляет compose; переменные путей нужны для запуска без Docker.

## Приватность

- Тексты сообщений не пишутся в логи. Из VK на диск не сохраняется ничего: ни переписка, ни файлы.
- Журнал агента (`state/actions.jsonl`, пишет бот) хранит текст просьбы и параметры вызовов; результаты вызовов
  панель не показывает и не хранит.
- VK-токен и ключи LLM вырезаются из всего, что панель отдаёт наружу, включая тексты ошибок.
- Панель видна только через Caddy по HTTPS; порт самой панели наружу не публикуется.
- Доверенный человек в доверенной беседе командует аккаунтом как владелец — доверяй через панель тем, кому доверил бы
  всё это и так.

## Локальная разработка

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest
WEB_PASSWORD=pw .venv/bin/python -m web.app   # панель на 127.0.0.1:8080
```

Для живых данных укажи в `.env` пути к `config/` и `state/` бота (`ACCESS_FILE`, `RUNTIME_FILE`, `PERSONAS_DIR`,
`STATE_DIR`); без `AI_URL` LLM работает в процессе панели с ключами из её `.env`.
