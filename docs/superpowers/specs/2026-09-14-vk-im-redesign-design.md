# Мессенджер `/im` в облике vk.com/im

Дата: 2026-09-14. Статус: согласовано с Актаном в чате, ждёт вычитки спеки.

## Цель

Страница `/im` веб-админки должна выглядеть и вести себя как веб-мессенджер VK (vk.com/im) в режиме
**без пузырей** — том, что включён в аккаунте Актана. Все размеры, цвета, шрифты и тени сняты с живого
vk.com/im 2026-09-14 (`getComputedStyle`, скачанные CSS-бандлы, токены `@vkontakte/vkui-tokens` 4.92,
тема `vkBase` светлая/тёмная). Логика мессенджера (роуты, поллинг, отправка, панель бота) остаётся;
меняются шаблоны, стили, клиентский JS и несколько полей view-моделей.

Не входит: эмодзи-пикер, стикеры, запись с микрофона, поиск по сообщениям, папки, реакции, выделение
нескольких сообщений, редактирование сообщений, прочие страницы админки.

## Референс

Скриншоты и правила VK лежат в scratchpad сессии (`vk-ref/NOTES.md`, `im-rules.txt`), они не в репозитории.
Всё, что нужно для реализации, перенесено в эту спеку числами.

Шрифт VK: `-apple-system, BlinkMacSystemFont, "Roboto", "Helvetica Neue", Geneva, arial, Tahoma, verdana, sans-serif`.

## Архитектура

- `web/templates/base.html`: навигация уезжает в `{% block nav %}` (по умолчанию нынешний `.topnav`), `<body>`
  получает `{% block body_class %}`. Список разделов (href, название, ключ, иконка) переезжает из шаблона
  в глобальную переменную Jinja `nav`, которую задаёт `render.Renderer` (`env.globals`); `.topnav` и оболочка
  `/im` рендерят один и тот же список.
- `web/templates/im.html`: `body_class = page-im`, блок `nav` = `partials/im_shell.html` (шапка + левая колонка),
  `main_class = im-shell`, тело = `partials/im.html`.
- `web/templates/partials/im_icons.html`: макрос `icon(name, cls='')` → `<svg class="ico {{cls}}"><use href="/static/vk-icons.svg#{{name}}"/></svg>`.
- `web/static/vk-icons.svg`: спрайт из SVG `@vkontakte/icons` 3.70.0 (MIT; лицензия в комментарии в начале файла),
  `<symbol id="<имя>" viewBox="0 0 N N">` с `fill="currentColor"`. Собирается разово скриптом из scratchpad,
  в репозиторий кладётся результат (как и остальные вендорные библиотеки в `web/static`). Набор:
  20: `message_outline_20 pulse_outline_20 users_outline_20 text_outline_20 key_outline_20 gear_outline_20
  reply_outline_20 robot_outline_20 cancel_20`; 24: `cancel_24 chevron_left_24 logo_vk_outline_24 robot_outline_24
  reply_24 delete_outline_24 add_circle_outline_24 magic_wand_outline_24 send_24 chevron_down_24 document_outline_24
  menu_outline_24`; 16: `mute_cross_16 pin_16 check_outline_16 check_double_outline_16 search_outline_16 cancel_16
  message_forward_outline_16`; 32: `play_circle_32 pause_circle_32`; 56: `messages_outline_56`. Все имена проверены
  по `icons/package/src/svg/<размер>/`.
- `web/static/im.css` переписывается целиком под токены выше. `web/static/im.js` дополняется компонентами
  `voice`, `viewer`, логикой прилипшего чипа, кнопки «вниз» и боковой панели; существующие компоненты
  `im`, `chat`, `composer`, `readMark` остаются.
- Python: `web/im/views.py` (поля `waveform`, `last_seen`, `sex`, флаг `unread` у `Row`, функция `presence`),
  `web/humanize.py` (`short_since`), `bot/vk.py` (`PROFILE_FIELDS` + `last_seen`), `web/im/routes.py`
  (`in_read` в `chat_ctx` при открытии чата). Роуты, htmx-контракты и id элементов, на которые опираются тесты
  и JS (`#messages`, `#chat-poll`, `#chat-state`, `#composer-error`, `#bot-slot`, `#chat-badge`, `#dialog-list`,
  `.dlg`, `.msg`, `.out`, `.head`, `.im-day`, `.im-more`, `.im-empty`, `data-id/from/ts`), сохраняются.

## Чат

### Шапка (56px)

Граница снизу 1px `--vk-sep`, фон `--vk-content`, паддинг 4 8, gap 8. Слева кнопка 32×32 радиус 6
`--vk-icon-2` (ховер `--vk-hover`): на десктопе `cancel_24` — закрывает чат (`$dispatch('im-close')`: компонент
`im` сбрасывает `sel`, заменяет содержимое `#chat` пустым состоянием из `<template x-ref="empty">` в `im.html`
и делает `history.pushState({}, '', '/im')`), на телефоне `chevron_left_24` — назад к списку (`im-back`, как сейчас).
Обе кнопки в разметке, показ по медиазапросу. Аватар 32,
название 13/16 500, под ним статус 13/16 `--vk-text-2`: беседа — «N участников» (`plural`); сообщество — «сообщество»;
пользователь — `presence` (ниже). Справа кнопки 32×32: `logo_vk_outline_24` «Открыть в VK» (`target=_blank`)
и `robot_outline_24` «Бот в этом чате» (панель). Бейдж режима — после названия в первой строке.

`presence(peer, now, tz)` (чистая функция в `views.py`, в шаблон идёт фильтром `presence(now, tz)`): `online` → «онлайн»; `last_seen == 0` → «»;
иначе «была в сети» / «был в сети» / «был(а) в сети» по `sex` (1 / 2 / 0) + пробел + `<60 с → «только что»`,
`<60 мин → «N мин назад»`, тот же день → «сегодня в HH:MM», предыдущий день → «вчера в HH:MM», иначе
«D месяца в HH:MM» (`MONTHS` из `views`; год не пишется). `Peer` получает поля `last_seen: float = 0`,
`sex: int = 0`; `Profiles.last_seen(uid)` читает `last_seen.time`, `Profiles.sex(uid)` — `sex`; `peer_of` заполняет
их только для `kind == "user"`. `PROFILE_FIELDS` в `bot/vk.py` дополняется `last_seen`. Сейчас в шапке для
пользователя пишется «не в сети» — заменяется на `presence`.

### Плеер голосовых

`Attachment` получает `waveform: tuple[int, ...] = ()` (VK: массив значений 0…31, обычно 128 штук).
Разметка `div.voice` с `x-data="voice(url, duration, waveform)"`: кнопка 32×32 `play_circle_32` / `pause_circle_32`
`--vk-accent`, margin-right 8; справа колонка: волна (SVG высотой 12) и под ней время 11/14 `--vk-accent`;
после волны кнопка «Aa» 32×20 радиус 8 фон `--vk-secondary` текст 12 500 `--vk-accent` — только если есть
расшифровка; по клику под плеером раскрывается блок `.transcript` 13/18 `--vk-text` с паддингом слева 12 и
полоской 2px `--vk-link` opacity .24.

Волна: число столбиков `n = clamp(round(duration * 2) + 20, 21, 80)` (1 с → 22 столбика ≈ 66px, как у VK);
`waveform` пересэмплируется в `n` значений (среднее по окну; пустой массив → все столбики 4/31); столбик —
`rect` шириной 2, скругление 1, шаг 3, высота `max(2, v / 31 * 12)`, выровнен по центру; проигранные столбики
`--vk-accent`, остальные `--vk-accent` с opacity .4. Клик по волне перематывает в долю ширины.
Звук — `new Audio(url)` с `preload: none`; `timeupdate` обновляет долю; при `play` компонент шлёт
`im-voice-play` (window), остальные плееры ставятся на паузу; при `ended` — сброс. Время: во время
воспроизведения — текущее `m:ss`, иначе длительность (`mmss`).

### Кнопка «вниз»

`#messages` оборачивается в `div.im-history` (`position: relative; flex: 1; min-height: 0`, прокручивается
по-прежнему `#messages`). `button.im-down` 40×40, круг, фон `--vk-modal`, тень `--vk-shadow-2`, `chevron_down_24`
`--vk-icon-2`, абсолютно в `.im-history`: справа 16, снизу 12 (то есть над композером); показывается, когда список прокручен выше чем на 120px от низа
(`!nearBottom()`); клик — плавная прокрутка вниз. Сверху справа бейдж 18px `--vk-accent` со счётчиком
входящих, пришедших поллингом, пока кнопка видна (`chat.pending`), обнуляется при достижении низа.

### Композер

Обёртка `.im-composer` паддинг `0 16px 16px` (телефон — `0 8px 8px`), фон `--vk-content`. Карточка `.box`: фон
`--vk-modal`, радиус 12, тень `--vk-shadow-3`. Сверху опциональные строки с границей снизу 1px `--vk-sep`:
- панель цитаты (`x-show="reply"`): паддинг 8 6, сетка «иконка | полоска | автор+текст | ×»: `reply_24`
  `--vk-accent` с полями 0 8, полоска 2px радиус 2 `--vk-forward-line`, автор 12.5/14 500 `--vk-link`,
  текст 13/18 в одну строку, кнопка × 36×36 `cancel_20` `--vk-icon` opacity .72;
- чип файла (`x-show="file"`): паддинг 8 12, `document_outline_24` `--vk-accent`, имя файла 13/18, размер
  `--vk-text-2`, × справа;
- ошибка `#composer-error` (OOB, как сейчас): 13/18 `--vk-red`, паддинг 8 12.

Строка ввода: паддинг 0 6, `align-items: flex-end`. Слева `label.attach` 36×36 (margin 4 0) с
`add_circle_outline_24` `--vk-icon` opacity .72 (ховер 1), заголовок «Голосовое из .ogg/.mp3», внутри скрытый
`input[type=file]`. Поле `textarea`: margin 12 6, 13/18, min-height 18, max-height `12 × 18`, без рамки и фона,
плейсхолдер «Сообщение» `--vk-text-2`; Enter/Shift+Enter/Esc — как сейчас. Справа кнопки 36×36:
`magic_wand_outline_24` «Черновик от бота» (тот же `hx-post`), `send_24` «Отправить» — `--vk-accent`, когда
есть текст или файл (класс `ready` от `:class`), иначе `--vk-icon` opacity .5; атрибут `disabled` не трогаем —
им управляет `hx-disabled-elt` на время запроса, а пустая отправка отсекается `@submit.prevent`-проверкой в
`composer` (и, как сейчас, сервером).

### Просмотрщик фото

Компонент `viewer` на `.im-chat`: `div.im-viewer` (`x-show="viewer"`, `x-cloak`) — `position: fixed; inset: 0`,
фон `rgba(0,0,0,.9)`, `z-index: 50`, картинка по центру `max-width: 100vw; max-height: 100vh; object-fit: contain`,
кнопка `cancel_24` белая 48×48 в правом верхнем углу. Открытие — `@click.prevent="viewer = url"` на ссылке фото
(ссылка на оригинал остаётся `href`, средняя кнопка/Ctrl-клик открывают как раньше); закрытие — клик по фону,
кнопке или Esc (`@keydown.escape.window`).

## Панель бота

колонке-обёртке `.im-convo`): панель — правая колонка с границей слева 1px `--vk-sep`, фон `--vk-content`,
своя прокрутка, не перекрывает композер. На телефоне — `position: fixed; inset: 0` поверх чата.

Содержимое (`im_bot.html`, те же формы и роуты):

Список и чат переключаются, как сейчас (`pane`); шапка страницы 48 с бургером остаётся над обеими панелями.

## Ошибки

Ничего нового: ошибки VK по-прежнему уходят в `#composer-error` (отправка) и тосты (поллинг, панель).
Плеер при ошибке загрузки звука (`error` у `Audio`) зовёт `toast("Не удалось загрузить голосовое", "bad")`
из `app.js` и возвращается в состояние «стоп». Просмотрщик при ошибке картинки просто показывает пустой фон — закрывается
как обычно.
